These days I split my time between operational/incident-management work and going deep on network automation: Ansible, Python, Terraform, EVPN/VXLAN, and lately MCP servers and streaming telemetry for network gear.

This blog is my running notebook — labs I build, things that broke and how I fixed them, and notes on tools as I actually learn them rather than after I've mastered them.
